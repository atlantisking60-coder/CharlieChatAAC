================================================================
  CHARLIE CHAT - DEPLOYMENT GUIDE (FOR ABSOLUTE BEGINNERS)
================================================================

Your app "Charlie Chat" is built with Flutter, which means you
can turn it into:
  1. A WEBSITE (anyone can use it in a browser)
  2. An ANDROID APP (downloadable from the Play Store)
  3. An iOS APP (downloadable from the Apple App Store)
  4. A WINDOWS APP (downloadable as a .exe file)

This guide covers ALL of them, step by step.


================================================================
  PART 0: THINGS YOU NEED BEFORE YOU START
================================================================

You already have Flutter installed, which is great. But you'll
also need:

FOR THE WEBSITE:
  - A GitHub account (free)           https://github.com
  - A Netlify account (free)          https://netlify.com
  - OR a Google Cloud account (free)  https://console.cloud.google.com

FOR THE ANDROID APP:
  - A Google Play Developer account   https://play.google.com/console
    (costs $25 one-time fee)
  - Java Development Kit (JDK 17)     (may already be installed)

FOR THE iOS APP:
  - A Mac computer (you can't do this on Windows)
  - An Apple Developer account        https://developer.apple.com
    (costs $99/year)
  - Xcode installed from the Mac App Store

FOR THE WINDOWS APP:
  - Visual Studio 2022 with "Desktop development with C++"
    (free) https://visual.microsoft.com


================================================================
  PART 1: BUILDING FOR WEB (WEBSITE)
================================================================

This is the EASIEST way to share your app with people.

STEP 1 - Open a terminal/command prompt
  - Press Windows key, type "cmd", press Enter
  - OR use the batch file: double-click "RUN WEB (Live Preview).bat"

STEP 2 - Navigate to your project
  Type this and press Enter:
    cd "C:\Users\Craig\Downloads\Charlie Chat"

STEP 3 - Build the web version
  Type this and press Enter:
    flutter build web --release

  This creates a folder called "build\web" with all the
  website files inside. It takes 1-5 minutes.

STEP 4 - Upload to Netlify (FREE hosting)
  1. Go to https://netlify.com and sign up (free)
  2. Once logged in, you'll see a page that says
     "Drag and drop your site output folder here"
  3. Open File Explorer and navigate to:
       C:\Users\Craig\Downloads\Charlie Chat\build\web
  4. Drag the ENTIRE "web" folder onto the Netlify page
  5. Wait for it to upload (may take a few minutes)
  6. Netlify will give you a URL like:
     https://random-name-12345.netlify.app
  7. THAT'S YOUR WEBSITE! Share that link with anyone!

  To use a custom name like "charliechat.com":
  1. Buy a domain name from Namecheap or Google Domains ($10-15/year)
  2. In Netlify, go to Site Settings > Domain Management
  3. Click "Add custom domain" and follow the instructions


================================================================
  PART 2: BUILDING FOR ANDROID (PLAY STORE APP)
================================================================

STEP 1 - Install Android Studio
  1. Go to https://developer.android.com/studio
  2. Download and install Android Studio
  3. Open Android Studio and go through the setup wizard
  4. It will install the Android SDK (this takes a while)

STEP 2 - Set up your Android phone for testing
  1. On your phone, go to Settings > About Phone
  2. Tap "Build Number" 7 times (yes, really)
  3. Go back to Settings > Developer Options
  4. Turn on "USB Debugging"
  5. Connect your phone to your computer with a USB cable
  6. On your phone, tap "Allow" when it asks about USB debugging

STEP 3 - Test on your phone first
  In the terminal, type:
    flutter run

  Your app should open on your phone!

STEP 4 - Build the release APK
  Type this:
    flutter build apk --release

  This creates a file at:
    build\app\outputs\flutter-apk\app-release.apk

  You can send this .apk file to anyone with an Android phone
  and they can install it directly (they'll need to allow
  "Install from unknown sources" in their settings).

STEP 5 - Upload to Google Play Store
  1. Go to https://play.google.com/console
  2. Pay the $25 one-time registration fee
  3. Click "Create Application"
  4. Enter "Charlie Chat" as the app name
  5. Fill in the store listing:
     - Title: Charlie Chat
     - Short description: AAC communication app
     - Full description: (write something about your app)
     - Upload screenshots (take them from your phone)
     - Upload a feature graphic (1024x500 pixels)
     - Upload an app icon (512x512 pixels)
  6. Under "App releases", click "Create new release"
  7. Upload the app-release.aab file (run this instead):
       flutter build appbundle --release
     This creates: build\app\outputs\bundle\release\app-release.aab
  8. Click "Review and publish"
  9. Wait 1-7 days for Google to review your app


================================================================
  PART 3: BUILDING FOR iOS (APPLE APP STORE)
================================================================

NOTE: You MUST have a Mac for this. Windows cannot build iOS apps.

STEP 1 - Install Xcode
  1. Open the Mac App Store
  2. Search for "Xcode" and install it (it's free but huge ~12GB)
  3. Open Xcode and agree to the license

STEP 2 - Install CocoaPods
  Open Terminal on your Mac and type:
    sudo gem install cocoapods

STEP 3 - Set up for iOS development
  1. Connect your iPhone to your Mac with a USB cable
  2. In Xcode, go to Window > Devices and Simulators
  3. Your phone should appear - click "Trust" on your phone

STEP 4 - Build and run
  In the terminal (from your project folder):
    flutter build ios --release

STEP 5 - Upload to App Store Connect
  1. Go to https://appstoreconnect.apple.com
  2. Sign in with your Apple Developer account ($99/year)
  3. Click "My Apps" > "+" > "New App"
  4. Fill in the app details
  5. Use Xcode to upload:
     - Open your project in Xcode
     - Product > Archive
     - Click "Distribute App"
     - Choose "App Store Connect"
  6. Wait 1-7 days for Apple to review


================================================================
  PART 4: BUILDING FOR WINDOWS (DESKTOP APP)
================================================================

STEP 1 - Install Visual Studio
  1. Go to https://visual.microsoft.com
  2. Download "Visual Studio 2022 Community" (free)
  3. During installation, check the box for
     "Desktop development with C++"
  4. Wait for it to install (it's big)

STEP 2 - Build the Windows app
  In the terminal, type:
    flutter build windows --release

  This creates an .exe file at:
    build\windows\x64\runner\Release\charlie_chat.exe

STEP 3 - Share it
  You can zip up the entire "Release" folder and share it.
  People just unzip it and double-click charlie_chat.exe to
  run it. No installation needed!


================================================================
  PART 5: FIREBASE SETUP (OPTIONAL BUT RECOMMENDED)
================================================================

Firebase is Google's backend service. Your app uses it for
user accounts and login. Right now it has placeholder values.

STEP 1 - Create a Firebase project
  1. Go to https://console.firebase.google.com
  2. Click "Create a project"
  3. Name it "charlie-chat" (or whatever you want)
  4. Follow the setup wizard

STEP 2 - Add your app to Firebase
  1. In the Firebase console, click the web icon (</>)
  2. Register your app with nickname "Charlie Chat Web"
  3. Firebase will give you a config object - COPY IT

STEP 3 - Update your code
  Open this file:
    C:\Users\Craig\Downloads\Charlie Chat\lib\firebase_options.dart

  Replace all the "AIzaSyYourWebApiKeyHere" and placeholder
  values with the real values from Firebase.

STEP 4 - Enable authentication
  1. In Firebase console, go to Authentication > Sign-in method
  2. Enable "Email/Password" or "Google Sign-in"
  3. This lets users create accounts and log in

================================================================
  TROUBLESHOOTING
================================================================

PROBLEM: "flutter: command not found"
  FIX: Close and reopen your terminal. If that doesn't work,
  reinstall Flutter from https://flutter.dev

PROBLEM: "No devices found"
  FIX: Make sure your phone is connected via USB and USB
  debugging is turned on. Run: flutter devices

PROBLEM: Build fails with dependency errors
  FIX: Run these commands in order:
    flutter clean
    flutter pub get
    flutter build web --release

PROBLEM: Website shows a blank page
  FIX: Make sure you uploaded the CONTENTS of the web folder,
  not the web folder itself. The index.html should be at the
  root of the uploaded files.

PROBLEM: Android app won't install on phone
  FIX: On the phone, go to Settings > Security and turn on
  "Unknown sources" or "Install unknown apps" for your
  file manager/browser.
